Zen / Firefox Setup
New tabs show a floating search bar?
Zen replaces the new-tab page with its URL-bar popup by default, so TabFlow never appears. Open about:config and set zen.urlbar.replace-newtab to false.
Good to know
"Background script: Stopped" in about:debugging is normal — it wakes on demand. Temporary add-ons unload when the browser restarts; a permanent install needs the package signed on addons.mozilla.org.
